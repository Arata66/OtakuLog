# 验证变更

代码修改后验证是保证质量的关键步骤。即使改动看起来很小，也可能引入编译错误或破坏已有测试。

## 步骤

1. **编译检查**
   ```bash
   mvn clean compile -q
   ```
   编译失败说明语法错误或类型不匹配，必须先修复。

2. **运行测试**
   ```bash
   mvn test -q
   ```
   测试失败说明改动破坏了已有行为。分析失败的测试用例，判断是测试需要更新还是代码有 bug。

3. **总结结果**
   - 编译状态：通过/失败
   - 测试状态：通过/失败（附测试数量）
   - 如有失败，说明具体错误和修复方案

## 何时使用

- 修改了任何 `.java` 文件后
- 新增或修改了 Controller/Service/Repository 方法后
- 修改了 DTO 或 Entity 字段后
- 修改了 Flyway 迁移文件后

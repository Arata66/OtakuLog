# 完整备份与恢复设计、实施与验收

日期：2026-10-08。承接第一阶段 D，用户已授权继续实施。

## 格式与边界

新增独立 `BackupService` 与显式备份 DTO，JSON 顶层包含 `format=otakulog-backup`、`version=1`、导出时间以及 anime、tags、groups、memberships、episodes。作品包含全部业务字段和审计时间；逐集记录包含可空观看日期、来源和审计时间。凭据与运行配置不进入备份。

备份内的 key 只是文件内引用，恢复时映射到本库新 ID。所有结构、版本、枚举、日期、长度、重复 key 和关联先完整校验。先预览，再由用户确认；真正写入时重复校验，整批事务提交，任何异常全部回滚。

## 合并规则

- 新作品恢复全部字段；已有作品以 Bangumi ID 和名称共同识别，两者指向不同对象、同名不同 Bangumi ID、同 ID 不同名称及本地重名歧义均拒绝。
- 已有作品的资料、审计时间和已有进度默认保留；可补充缺失 Bangumi ID，导入更高进度时同步进度与状态。预览明确说明合并保留策略。
- 标签和分组按名称复用，关联取并集；同名分组资料不同会冲突，避免覆盖现有分类设置。
- 同一集的已知日期不同或已知日期的来源不同会冲突；导入未知日期不覆盖已有日期，可用备份里的已知日期补齐本地未知日期。
- 不删除本地额外作品、标签、分组、关联或记录。重复恢复不新增重复项，也不修改未变化的审计时间。
- 历史数据中完成状态与进度不一致时按原数据保留，不借恢复猜测或修复历史。
- 旧 JSON 数组转为兼容输入：标签兼容字符串/字符串数组/对象数组，无逐集日期时仅补未知日期与 IMPORT 来源；缺失的业务日期不补成今天，已有进度倒退会拒绝。

## 接口与界面

- 保留 `/api/anime/export` 和 `/api/anime/import`，改为共用独立备份服务；新增 `/api/anime/import/preview` 返回数量、警告及冲突，不写数据库。
- 本地文件导入先预览，显示新增/匹配作品、标签、分组、逐集记录和警告，确认后才写入。
- WebDAV 推送完整格式；拉取新增预览步骤，确认时携带文件摘要，再次下载若内容已变化则拒绝本次拉取。直接 API 拉取仍进行同一套结构和冲突校验。
- 本阶段不实现双向同步冲突自动合并、删除传播、定时上传或加密备份。

## 实施顺序

1. 基于现有导入/导出入口添加行为用例，先复现完整格式、恢复关联、预览与冲突缺失。
2. 实现 DTO、解析/校验、身份匹配与原子合并，抽离旧导入逻辑；保留审计时间。
3. 接入 API、本地预览确认、WebDAV 预览摘要与统一格式。
4. 验证空库恢复、ID 重映射、重复导入、未知日期、身份/日期冲突、非法关联、旧格式和写入中途回滚；补真实 MySQL 恢复验证与模拟 WebDAV HTTP 验证。
5. Java 17 干净编译、全套 Java/Node 用例、JS 语法及空白检查；更新 README、阶段入口和记忆，重建预览并只读验证现有数据，提交并推送。

## 验证结果

- 初始测试复现：导出仍为数组、完整对象无法导入，完整恢复与重复恢复失败；前端 5 个新增恢复用例全部失败。补充边界用例复现未知审计时间被补成当前时间、缺字段被默认接受，以及观看季度长度与 MySQL 列限制不一致。
- 最终 Java 17 `clean compile test package` 通过；130 个 Java 用例全部通过，无失败、错误或跳过：44 个原有业务、29 个安全、27 个观看一致性、20 个备份恢复、4 个模拟 WebDAV HTTP、6 个真实 MySQL 用例。
- 22 个 Node 行为用例、4 个 JS 语法检查和空白检查通过；恢复冲突、取消确认、失败预览不写入、提交原文件及 WebDAV 摘要携带均有覆盖。
- 真实 MySQL 随机隔离库验证：完整导出、删除测试数据后恢复、编号映射、标签与分组关联、已知与未知日期、来源、审计时间、重复恢复无重复项。测试库仅删除本轮自己创建的库。
- 已后台启动当前工作区 JAR。真实 HTTP 登录、主页、完整导出、只读导入预览、最新前端资源与匿名导出 401 均通过。自用库 11 部作品、62 条逐集记录仍可访问；日期校验值保持 `120172387655`，没有在自用库执行恢复。
- README、`docs/备份与恢复.md`、整体路线、AGENTS 规则指针和本地记忆已同步。下一步 E 可解释统计；B 容器验收仍待可运行 Docker 引擎。
- 本轮未连接真实 WebDAV 服务、未做浏览器端到端验证；WebDAV 传输通过模拟 HTTP 验证，不宣称双向自动同步或生产部署已完成。

## 实现补充

完整格式显式包含字段；可空字段用 `null`，未知审计时间原样保留。标签创建时间遵循数据库非空约束。旧数组展开逐集记录前校验进度，一次最多补齐 100000 条记录，防止错误大数字导致内存耗尽。观看季度校验使用实际 MySQL `VARCHAR(20)` 限制。

前端沿用原有确认对话框，先展示数量和警告，冲突以纯文本展示，不插入未转义 HTML。静态缓存升级到 v7。

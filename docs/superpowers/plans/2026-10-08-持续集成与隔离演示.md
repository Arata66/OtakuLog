# 持续集成与隔离演示实施计划

用户已授权决定顺序并继续。沿用实施工作区和分支，本节在当前会话实施，验收后统一提交并立即推送。

## 目标与设计

为每次推送和 PR 自动运行 Java 17、Node 22、真实 MySQL 8 检查；提供可重复的虚构演示数据和单独的本地演示进程，完成界面写入验收。保留 JPA validate 与 Flyway，生产代码、数据格式和自用库均不改变。

采用 GitHub Actions 加无依赖 Node 启动脚本。仅 H2 验证不能覆盖迁移；依赖 Compose 的演示启动又受本机 Docker 不可用限制，因此本节直接使用本地 MySQL。启动脚本只接受回环数据库地址，随机生成 otakulog_demo_ 前缀库名，以 CREATE DATABASE 创建成功作为拥有标记；默认绑定 127.0.0.1:18080，拒绝占用日常预览的 8080。

脚本从最新 target JAR 启动独立 Java 子进程，使用显式数据库参数、validate/Flyway 和每次随机的演示登录凭据，登录成功后通过 CSRF 保护的恢复预览与导入接口加载固定虚构备份。随机凭据防止端口竞争时误向其他应用导入。启动失败、正常退出或 Ctrl+C 时先停止自己持有的子进程，再删除本次成功创建的库；创建失败不得删除任何库。不实现后台守护或按任意 PID 停进程。强制终止/断电可能残留演示库，文档提供明确人工核对步骤。

## 文件职责

- `.github/workflows/ci.yml`：推送、PR、手动运行；只读仓库权限；MySQL 服务健康检查；Java 构建、Node 检查、演示冒烟和测试报告。
- `scripts/demo.cjs`：前台演示生命周期与 CLI；输出地址和临时凭据，支持 Ctrl+C 与测试进程通信退出。
- `scripts/lib/demo-config.cjs`：本地地址、端口、随机库名、JVM 参数与数据库命令。
- `scripts/lib/http-session.cjs`：独立 Cookie 会话、登录、CSRF 读写，不使用真实用户浏览器会话。
- `src/test/resources/fixtures/demo-backup.json`：虚构作品、标签、分组、明确/未知/LEGACY 记录，包含距完成一集的作品，不引用用户数据和外部封面。
- `src/test/java/com/otakulog/service/DemoFixtureTest.java`：备份有效性、重复恢复和来源保留。
- `src/test/js/demo-tools.test.cjs`：拒绝业务库/非本地地址/非法端口、数据库创建与清理边界、独立 HTTP 会话。
- `src/test/js/demo-smoke.test.cjs`：显式 OTAKULOG_DEMO_TEST=true 时启动真实隔离应用，验收记看、完成、退集、核对、冲突与退出清理。
- `docs/持续集成与演示.md`、README、路线和记忆：运行步骤、验证结果、强制退出边界。

## 本地验收结果（2026-10-09）

178 个 Java 测试（含9个真实 MySQL和3个虚构备份测试）、69 个 Node 测试（含真实演示冒烟）全部通过，无失败或跳过；10个脚本语法、工作流 YAML 解析与空白检查通过。真实演示冒烟验证正常停止后随机库不存在。隔离浏览器验证完成最后一集、退回追中、详情联动以及未知日期补录后的首页刷新；确认弹窗取消和多窗口竞争尚未全面验收。

跨日验收终端被强制中断，产生一个本次演示残留库；确认演示进程已停止、无连接且四部作品均为虚构样例后，仅清理该库。这验证了强制中断的边界，不将其描述为自动清理成功。自用库仍11部作品、62条逐集记录，日期校验120172387655；8080已恢复并通过真实登录与只读接口检查。

# 今日放送核对实施计划

日期：2026-10-10。用户已确认开始修复，沿用可靠自用工作区和验证后自动合并流程。

**目标**：已放送完结但未补完的旧番只保留在继续观看，首页今日参考必须有当前 Bangumi 日历依据。

**结构**：`DailyWatchService` 保持本地只读快照，默认今日参考为未核实；新增 `DailyAiringService` 和 `/api/watch/airing` 独立核对。外部请求在数据库事务外执行，复用现有 30 分钟 Bangumi 日历缓存。前端先显示继续观看，再异步更新放送区，失败不回退旧星期。

**技术**：Java 17、Spring Boot、原生 JS、JUnit、Node、Playwright；无数据库迁移，静态缓存升级 v15。

## 规则

- 从全部可继续作品中核对并计数，展示最多六部；排序沿用明确观看日期、自定义排序、名称和编号。
- 有 Bangumi ID 时仅按 ID 匹配，不以同名覆盖错误 ID；无 ID 时按去首尾空格和大小写归一后的完整名称，匹配日文名或中文名，且只接受唯一日历作品。
- 使用日历中的星期，不沿用本地旧星期；本地或日历明确未来开播的作品排除。不能通过集数或个人看完日期猜放送结束时间。
- 有效核对返回 `VERIFIED`、准确数量及列表；失败、空日历或无效日历返回 `UNAVAILABLE`、数量 null 和空列表。默认本地入口返回 `UNVERIFIED`、数量 null 和空列表。
- 日历未收录不代表确定完结，界面只说明当前日历没有匹配，不猜本周停播或实际剧集上线。
- 日常入口刷新和观看写入失败沿用现有保护；过期放送响应不能覆盖新请求、进度或跨日日期。

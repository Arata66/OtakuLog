# 以图搜番与外部服务

## 使用方式

登录后在添加区域选择截图，页面上传到本站 `POST /api/tracemoe/search`，表单字段为 `image`，请求需要登录会话和 CSRF 令牌。识别结果最多显示五个候选，包括名称、集数、相似度和预览图。识别仅提供候选，点击添加后仍需核对作品资料并提交表单。

本站服务端把图片原始字节通过 POST `/search` 发给 trace.moe，使用上传文件的媒体类型；缺少类型时使用 `application/octet-stream`。图片内容放在请求体，避免 Base64 查询参数造成请求地址过长。请求连接和读取超时均为 10 秒。协议依据：[trace.moe 官方文档](https://soruly.github.io/trace.moe-api/#/docs)。

返回的本地数据字段包括 `animeName`、`filename`、`episode`、`from`、`to`、`confidence`、`image`、`video` 和 `allResults`；`confidence` 是相似度乘以 100 后取整，并不保证识别正确。服务端没有候选时返回 404；额度耗尽、上游 HTTP 错误或网络失败按外部服务失败返回 502。失败后可稍后重试或手动填写名称。

## 验证与边界

`TraceMoeServiceTest` 使用模拟 HTTP 服务，验证 64 KiB 图片的实际请求字节和媒体类型、缺少类型时仍能上传、空结果、最多五个候选、额度耗尽及连接失败。用例无需公网或私人截图，随 Java 测试在 CI 运行。

2026-10-10 使用 `scripts/demo.cjs` 的随机独立库和临时登录执行实际联动：

| 入口 | 结果 |
|------|------|
| Bangumi 名称搜索 | 返回两条结果 |
| Bangumi 作品详情与剧集 | 作品 253 可查询，返回 26 集 |
| Bangumi 放送日历 | 返回 104 条参考记录 |
| Bangumi 排行榜与当季列表 | 各返回两条结果 |
| trace.moe 本地图片上传入口 | 官方公开演示图 37335 字节，返回五个候选，最高相似度 99% |

以上为当次服务可用性记录，返回数量与识别结果可能随外部数据变化。比较导出时排除导出时间，核对隔离库业务内容未变，退出后只清理本次创建的库。未向自用库写入验收数据。

## Bangumi 收藏导入

登录后选择“同步 → 从 Bangumi 导入”，输入个人主页 `/user/` 后的账号标识，显示昵称不能作为可靠标识。本站 `POST /api/bangumi/import/{username}` 需要会话与 CSRF，只读取公开动画收藏，每次最多200条，不使用私人访问令牌。协议参考 [Bangumi 官方 API](https://bangumi.github.io/api/)。

网络分页全部完成后才进入整批写入事务，后续页失败不会留下部分作品。上游缺失或错误的 `data` 返回502，明确的空列表才表示空收藏；中途写入失败整批回滚。

- 按 Bangumi ID 和作品名称去重，已有作品资料、进度和逐集来源保留。
- 想看、看过、在看、抛弃分别映射计划、完成、追中、放弃；搁置和未知状态没有可靠映射，跳过并提示需核对。
- 集数未知或为零、进度超出集数、想看却已有进度等矛盾数据跳过，不能猜成12集或追中。
- 完成状态以已知总集数恢复进度；缺少逐集观看日期时记录为 `IMPORT` 且日期为NULL，不根据收藏更新时间猜观看日期或个人看完日期。
- 单批逐集补录上限100000条，超出时拒绝整批导入。收藏评分、评论和标签不自动映射；需按本地资料核对。

结果字段 `created` 为新增，`skipped` 为全部跳过，`needsReview` 是跳过中需核对的数量，`total` 是本次读取数量；新增加跳过等于总数。页面成功后刷新列表、统计、继续观看与热力图，失败后恢复按钮并保留数据。

2026-10-10验收：12个 Java 用例覆盖分页、上限、空收藏、异常、事务边界、重复保留、未知日期与整批回滚；4个 Node 用例覆盖界面结果和按钮恢复。Chromium通过本地模拟HTTP上游调用真实后端，在随机 MySQL 库核对有效/重复/需核对/503及导入后记看。

用户提供的公开账号实际返回1条收藏：隔离库新增1部已完成作品、8条未知日期 `IMPORT` 记录，重复导入新增0；退出后确认仅本次隔离库已清理。账号和当时收藏内容不写入固定测试样例或日志报告，不在自用库执行写入验收。

自动匹配的写入流程及真实 WebDAV 服务仍待验收；模拟 WebDAV 测试继续覆盖备份预览和摘要确认。Docker 引擎仍不可连接，容器构建、健康依赖和卷重启仍待实际验收。

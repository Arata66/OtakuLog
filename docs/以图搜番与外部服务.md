# 以图搜番与外部服务

## 使用方式

登录后在添加区域选择截图，页面上传到本站 `POST /api/tracemoe/search`，表单字段为 `image`，请求需要登录会话和 CSRF 令牌。识别结果最多显示五个候选，包括名称、集数、相似度和预览图。识别仅提供候选，点击添加后仍需核对作品资料并提交表单。

本站服务端把图片原始字节通过 POST `/search` 发给 trace.moe，使用上传文件的媒体类型；缺少类型时使用 `application/octet-stream`。图片内容放在请求体，避免 Base64 查询参数造成请求地址过长。请求连接和读取超时均为 10 秒。协议依据：[trace.moe 官方文档](https://soruly.github.io/trace.moe-api/#/docs)。

返回的本地数据字段包括 `animeName`、`filename`、`episode`、`from`、`to`、`confidence`、`image`、`video` 和 `allResults`；`confidence` 是相似度乘以 100 后取整，并不保证识别正确。服务端没有候选时返回 404；额度耗尽、上游 HTTP 错误或网络失败按外部服务失败返回 502。失败后可稍后重试或手动填写名称。

## 验证与边界

`TraceMoeServiceTest` 使用模拟 HTTP 服务，验证 64 KiB 图片的实际请求字节和媒体类型、缺少类型时仍能上传、空结果、最多五个候选、额度耗尽及连接失败。用例无需公网或私人截图，随 Java 测试在 CI 运行。

2026-10-10 使用 `scripts/demo.cjs` 的随机独立库和临时登录执行实际联动：

| 入口 | 结果 |
|------|------|
| Bangumi 名称搜索 | 返回两条结果 |
| Bangumi 作品详情与剧集 | 作品 253 可查询，返回 26 集 |
| Bangumi 放送日历 | 返回 104 条参考记录 |
| Bangumi 排行榜与当季列表 | 各返回两条结果 |
| trace.moe 本地图片上传入口 | 官方公开演示图 37335 字节，返回五个候选，最高相似度 99% |

以上为当次服务可用性记录，返回数量与识别结果可能随外部数据变化。比较导出时排除导出时间，核对隔离库业务内容未变，退出后只清理本次创建的库。未向自用库写入验收数据。

Bangumi 收藏导入、自动匹配的写入流程及真实 WebDAV 服务尚未在本节验收；模拟 WebDAV 测试继续覆盖备份预览和摘要确认。Docker 引擎仍不可连接，容器构建、健康依赖和卷重启仍待实际验收。

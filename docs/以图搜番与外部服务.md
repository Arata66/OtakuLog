# 以图搜番与外部服务

## 使用方式

登录后在添加区域选择截图，页面上传到本站 `POST /api/tracemoe/search`，表单字段为 `image`，请求需要登录会话和 CSRF 令牌。识别结果最多显示五个候选，包括名称、集数、相似度和预览图。识别仅提供候选，点击添加后仍需核对作品资料并提交表单。

本站服务端把图片原始字节通过 POST `/search` 发给 trace.moe，使用上传文件的媒体类型；缺少类型时使用 `application/octet-stream`。图片内容放在请求体，避免 Base64 查询参数造成请求地址过长。请求连接和读取超时均为 10 秒。协议依据：[trace.moe 官方文档](https://soruly.github.io/trace.moe-api/#/docs)。

返回的本地数据字段包括 `animeName`、`filename`、`episode`、`from`、`to`、`confidence`、`image`、`video` 和 `allResults`；`confidence` 是相似度乘以 100 后取整，并不保证识别正确。服务端没有候选时返回 404；额度耗尽、上游 HTTP 错误或网络失败按外部服务失败返回 502。失败后可稍后重试或手动填写名称。

## 验证与边界

`TraceMoeServiceTest` 使用模拟 HTTP 服务，验证 64 KiB 图片的实际请求字节和媒体类型、缺少类型时仍能上传、空结果、最多五个候选、额度耗尽及连接失败。用例无需公网或私人截图，随 Java 测试在 CI 运行。

2026-10-10 使用 `scripts/demo.cjs` 的随机独立库和临时登录执行实际联动：

| Bangumi 名称搜索 | 返回两条结果 |
| Bangumi 作品详情与剧集 | 作品 253 可查询，返回 26 集 |

## Bangumi 收藏导入

登录后选择“同步 → 从 Bangumi 导入”，输入个人主页 `/user/` 后的账号标识，显示昵称不能作为可靠标识。先完整读取公开动画收藏并逐条预览，再明确确认；不使用私人访问令牌，不导入私密收藏。协议参考 [Bangumi 官方 API](https://bangumi.github.io/api/)。

网络分页全部完成后才进入整批写入事务，后续页失败不会留下部分作品。上游缺失或错误的 `data` 返回502，明确的空列表才表示空收藏；中途写入失败整批回滚。

- 按 Bangumi ID 和作品名称去重，已有作品资料、进度和逐集来源保留。
- 想看、看过、在看、抛弃分别映射计划、完成、追中、放弃；搁置和未知状态没有可靠映射，只保留独立外部收藏并提示原因。
- 集数未知或为零、进度超出集数、想看却已有进度等矛盾数据跳过，不能猜成12集或追中。
- 完成状态以已知总集数恢复进度；缺少逐集观看日期时记录为 `IMPORT` 且日期为NULL，不根据收藏更新时间猜观看日期或个人看完日期。
- 单批逐集补录上限100000条，超出时拒绝整批导入。可勾选将个人评分和收藏标签复制给新增作品，已有作品仍不覆盖；未评分保持未知，不使用大众评分代替。
- 原始评分、收藏标签、评论及上游更新时间保存在外部收藏，来源标签不等于作品官方题材。评论可查看和复制，不自动生成感想、观看日期或AI请求；上游更新时间也不能当作收藏或观看时间。
- 逐页50条，保护上限10000条／200页，整轮读取限制三分钟。错误总数、后续页失败、重复编号和提前结束明确失败，不静默截断；数量变化另有提示，不能保证上游并发修改期间的事务快照。
- 预览绑定本地登录身份，15分钟过期，原始资料不接受客户端回传。确认前重新核对本地变化，整批原子写入；请求UUID持久防重，重启或响应丢失后仍能返回原结果，同键不同选项拒绝。
- 外部收藏每个来源账号与作品ID唯一定位，消失条目不自动删除，版本变化须核对。2/3/4/5状态默认用于推荐排除，搁置或集数未知也有效；1想看不推断为已看。明确打开包括已看时可显示2已看，3/4/5仍避开。可在面板里查看或明确删除外部记录，本地作品保留。
- 外部收藏与导入历史各最多100000条，原始JSON每条最多64000字节；均纳入完整备份v4，恢复不外发。

结果字段 `created` 为新增本地作品，`skipped` 为未新增作品，`needsReview` 是其中需核对的数量，`total` 是本次读取数量，`externalSaved` 为保留的外部记录数；新增加未新增等于总数。成功后刷新列表、统计、继续观看与热力图，失败后恢复按钮。关闭读取面板取消客户端等待；服务器已开始的只读请求可能继续完成，不会自动写入。

| API | 用途 |
|-----|------|
| `POST /api/bangumi/import/preview`，`{"username":"账号标识"}` | 只读预览，返回预览编号、数量、到期时间和逐条原因 |
| `POST /api/bangumi/import/confirm`，`previewKey`、`requestKey`、`importScores`、`importTags` | 只接受编号与选项，原始数据留在服务端 |
| `GET /api/bangumi/collections?page=0&size=20` | 分页查看原始外部收藏 |
| `DELETE /api/bangumi/collections/{key}?expectedVersion=0` | 版本核对后删除外部收藏，不删除本地作品 |

上述接口均需登录，写入或预览POST需要CSRF。预览不存在、过期或属于其他登录身份返回404；本地变化或同键选项不同返回409。旧直接导入接口 `/api/bangumi/import/{username}` 已停用，返回400并提示新流程。

2026-10-10验收：12个 Java 用例覆盖分页、上限、空收藏、异常、事务边界、重复保留、未知日期与整批回滚；4个 Node 用例覆盖界面结果和按钮恢复。Chromium通过本地模拟HTTP上游调用真实后端，在随机 MySQL 库核对有效/重复/需核对/503及导入后记看。

用户提供的公开账号实际返回1条收藏：隔离库新增1部已完成作品、8条未知日期 `IMPORT` 记录，重复导入新增0；退出后确认仅本次隔离库已清理。账号和当时收藏内容不写入固定测试样例或日志报告，不在自用库执行写入验收。

# 口味画像

口味画像从你留下的感想中整理依据。它保留“喜欢什么”和“不满意什么”，并允许同一部作品同时出现在两边；只有经过你确认、来源仍有效的观点才进入首页总结。

## 使用方式

在作品详情中保存观影记忆，再打开对应记录的“整理观点”。手工填写原文引用、自己的表述、喜欢或不满意、评价维度和因素即可保存，不需要配置 AI。

也可以选择感想原文、打动你的地方或不满意的地方，预览后点击“明确发送并整理”。预览显示 DeepSeek、实际选择文字、范围与语境、粗略输入用量、1200 token 输出上限、估算费用和当天剩余次数。只有发送操作调用模型；保存感想、确认观点、刷新总结和备份恢复均不调用。

模型最多生成六条候选。逐条确认、修改或拒绝，候选不会自动进入总结；原始模型建议保留供核对。只表达情绪而没有具体原因的感想可以得到零条候选，这不代表不喜欢作品。选文字数合计最多6000个Java字符，长文需要自己明确选择连续片段，系统不静默截断。

编辑感想会使旧版本的观点失效，并从当前总结排除。再次查看原文、核对有效引用后，明确保存到新的来源版本才会重新纳入。新的回望可以另写一条，保留当时与现在的不同感受；不需要填不确定的观看日期。

## 总结口径

- 只使用已确认且来源版本当前的观点，待核对、拒绝和失效记录仍保留。
- 相同维度和规范化后相同的因素归为一组；不猜同义词。需要合并时，可以自己修改因素文字。
- 喜欢与不满意分别展示依据、作品、原文引用、评价范围、语境和日期。同一作品的多次回望只计一个作品条目。
- 单作品的结论限定“在这部作品中”；多作品显示在几个作品条目中出现，不生成固定人格类型或精确喜欢概率。

口味画像不自动推荐作品。[可控推荐](可控推荐.md)使用明确标签或有正向评分的作品标签；确认观点到推荐依据的可核对映射仍待下一阶段，不把自由感想自动当成题材条件。

## 配置与调用记录

默认关闭 AI，手工整理可以独立使用。通过环境变量或仓库外 Spring 配置启用，密钥不能写入源代码、前端或备份。

| 环境变量 | 默认值 | 含义 |
|---|---|---|
| `AI_ENABLE` | `false` | 启用按需整理 |
| `DEEPSEEK_API_KEY` | 空 | 服务端密钥 |
| `AI_ENDPOINT` | `https://api.deepseek.com/chat/completions` | 完整请求地址，测试另允许回环HTTP |
| `AI_DAILY_LIMIT` | `20` | 本应用每日预留次数，允许0至1000 |
| `AI_CONNECT_TIMEOUT_MS` | `5000` | 连接超时 |
| `AI_RESPONSE_TIMEOUT_MS` | `30000` | 响应及完整正文等待上限 |
| `AI_INPUT_PRICE_PER_MILLION` | `2` | 每百万输入token的估算单价，人民币 |
| `AI_OUTPUT_PRICE_PER_MILLION` | `8` | 每百万输出token的估算单价，人民币 |

模型固定为 `deepseek-flash`，明确关闭思考模式。默认估算按官方Flash高峰缓存未命中的输入与输出单价配置；价格可变，估算不能当成实际账单或费用硬上限。实际用量以供应商响应的 `usage` 为准，缺失部分显示未知，不补成零。参考[官方价格说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)和[调用接口说明](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)。

调用一旦预留即计入次数，失败、来源变化或结果未知均不退额，也不自动重试。相同来源版本与相同选择的成功结果复用缓存，保留你已修改、拒绝或删除的结果。同一已预留请求键始终不会再次外发；响应丢失后先读取已有请求状态，不能换新键自动重发。核对尚未找到记录时，可明确选择按原编号和原选文重试；开始新的整理也须单独确认，旧编号保留供核对。

界面的累计用量来自本应用保留的调用历史，不代表供应商账户余额或其他程序的消耗。运行中请求超过120秒、审计时间在未来或来自备份恢复时显示结果未知；新的显式请求仍受每日次数限制。

## 备份与来源删除

完整JSON与WebDAV备份从版本3起包含记忆、观点和非秘密调用历史。模型原建议、自己的改写、拒绝与失效状态、版本、审计时间和可得用量均保留。备份不包含密钥、运行配置或单独保存的发送全文。

恢复不会调用模型或恢复未完成任务；历史RUNNING保持原状态，显示结果未知。同一UUID内容或归属不同则整批冲突；恢复不会降低本地当天已预留的次数。旧版本2、1及旧数组仍可读取，不删除本地新集合，详见[备份与恢复](备份与恢复.md)。

删除记忆或作品会清理相应观点。调用历史保留记忆UUID与计数，防止通过删除来源重置当天额度；它不依赖来源仍然存在。

## 接口与事务

全部接口要求登录，写入及POST预览沿用CSRF保护。错误归属返回404，非法输入返回400，来源或修订版本冲突返回409。AI完成失败返回502，来源变化返回409，错误响应仍可包含安全请求状态供核对。

| 接口 | 用途 |
|---|---|
| `GET /api/anime/{animeId}/memories/{memoryId}` | 精确读取来源原文 |
| `GET/POST /api/anime/{animeId}/memories/{memoryId}/insights` | 读取观点或手工新增 |
| `PUT/DELETE /api/anime/{animeId}/memories/{memoryId}/insights/{insightId}` | 按修订版本修改或删除 |
| `POST /api/anime/{animeId}/memories/{memoryId}/insights/ai/preview` | 只读发送预览 |
| `POST /api/anime/{animeId}/memories/{memoryId}/insights/ai/extract` | 以稳定请求键按需整理 |
| `GET /api/taste/ai/calls/{requestKey}` | 核对持久化请求状态 |
| `GET /api/taste/ai/usage` | 本应用次数与已知用量 |
| `GET /api/taste/profile` | 有效确认观点的本地汇总 |

观点写入核对 `sourceVersion`，修改与删除另核对 `expectedVersion`。手工新增的稳定键为规范小写UUID；引用必须是对应原文字段中的非空白连续片段。原始模型字段与来源只读，用户修改当前字段。

V11新增 `memory_insight`，V12新增 `ai_call` 和唯一预算行 `ai_quota`，JPA保持 `validate`。预算相关操作先锁预算行再锁作品；模型HTTP在事务外，完成时再次核对来源，过期响应只保存历史与可得用量，不保存候选。恢复先锁预算行、固定导入行再锁作品，在一个事务中校验并合并全部集合与预算，失败全部回滚。

演示及自动化回归仅使用随机隔离库、虚构感想和显式回环假AI服务，不继承自用凭据；真实供应商冒烟单独使用仓库外配置与虚构文本。详见[持续集成与演示](持续集成与演示.md)及[浏览器核心回归](浏览器核心回归.md)。

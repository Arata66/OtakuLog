# 年度统计口径

年报区分完成作品与年度观看记录，避免把跨年作品的整部集数算进完成那一年。入口仍为登录后的年度报告，API 为 `GET /api/report/annual/{year}` 与 `/api/report/annual/latest`。

## 四项统计

| 显示项 | 规则 |
|--------|------|
| 完成番剧 | 当前状态为 FINISHED，完成日期 endDate 落在所选年份的作品数 |
| 有明确日期的观看集数 | 逐集 watchedDate 落在该年，来源为 WATCHED、MANUAL、IMPORT；包含追中、完成和搁置作品 |
| 平均评分 | 当年完成作品中 0 < score <= 10 的有效评分均值，保留一位小数；无有效评分显示“未评分” |
| 估算观看时长 | 明确日期观看集数 × 24 分钟 ÷ 60，保留一位小数；实际单集时长可能不同 |

例如一部 12 集作品于 2027 年完成，其中 2026 年有 3 集明确日期记录：2026 年观看量计 3 集，完成数计 0；2027 年完成数计 1，观看量只统计 2027 年的逐集记录。

月度图使用逐集日期归月后的观看集数。API 同时返回按完成日期归月的完成数、有效评分数量和均分。月均分与年均分使用同一评分规则，未评分作品不进入分母。TOP 榜、评分分布和标签偏好继续针对当年完成作品，追中作品的评分不混入完成作品均分。

## 历史来源与缺失数据

`LEGACY` 代表来源不可考的历史记录，其中可能含 V5 旧估算日期。所选年份有日期的 LEGACY 记录单独显示“历史来源不明”，不进入明确日期观看集数或估算时长。迁移时没有把这些记录升级为真实观看事实，年报也不自动升级。

年报还展示以下**全库**覆盖提示，它们不能被解释为该年遗漏的观看数量：

- 日期未知的逐集记录：无法确定观看年份，不按创建时间、完成日期或导入时间猜测。
- 进度缺少逐集记录：按当前进度范围内真正缺失的集号计数，不拿最大集号代替完整记录。
- 完成日期未知的已完成作品：不猜完成年份，不进入年度完成数。

没有记录的历史作品也不回退到整部集数或平均分摊。数字为 0 表示当前证据下没有可计入的记录，不表示用户从未观看；历史参考数量和覆盖提示用于解释差异。主动补录的明确日期可以正常统计，未知日期仍保持未知。

热力图保留现有历史日期兼容逻辑，会展示有日期的 LEGACY 记录；因此它与年报明确日期观看量可能不同。年报的历史来源数量用于核对这些差异。本阶段不修改原始记录或热力图。

## API 字段

所有接口需要登录，年份范围为 1000–9999，非法年份返回 HTTP 400。响应继续使用 `ApiResponse`，以下字段位于 `data`：

| 字段 | 含义 |
|------|------|
| `year` | 所选年份；latest 为当前年份 |
| `totalWatched` | 当年完成作品数，沿用原字段名 |
| `totalEpisodes` | 当年明确日期观看集数，已由旧“完成作品总集数”口径修正 |
| `watchedAnimeCount` | 上述观看记录涉及的不同作品数 |
| `averageRating` / `ratedAnimeCount` | 当年完成且有效评分作品的均分与数量；数量为 0 时均分原始值为 0，客户端显示“未评分” |
| `watchingHours` | 基于明确日期观看量的估算小时数 |
| `minutesPerEpisode` / `watchingHoursEstimated` | 固定 24 与 true，说明估算依据 |
| `legacyDatedEpisodes` | 当年日期范围内的 LEGACY 记录数，不并入 totalEpisodes |
| `undatedEpisodeRecords` | 全库日期未知的逐集记录数 |
| `missingEpisodeRecords` | 全库当前进度范围内缺少的逐集记录数 |
| `undatedFinishedAnimeCount` | 全库缺少完成日期的已完成作品数 |
| `monthlyStats` | 固定 12 个月，每项含 month、count（完成数）、episodes（明确观看数）、legacyEpisodes、ratedCount、avgScore |
| `topAnimes` / `tagDistribution` / `ratingDistribution` | 当年完成作品的已评分榜单、标签及有效评分分布 |

读取使用只读一致性快照，不写回或修补数据。API 消费方应使用 `ratedAnimeCount` 区分未评分，使用来源与覆盖字段解释观看量，不能将全库缺失数量归入当前报告年份。

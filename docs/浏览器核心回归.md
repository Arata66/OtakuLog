# 浏览器核心回归

## 覆盖范围

这套测试在真实Chromium中加载页面，通过临时账号表单登录、输入和点击调用真实业务接口。每个用例使用新随机库和固定虚构样例，结束时先停止自己的Java子进程，再查询确认本次库已删除；测试失败也执行清理。不能把现有自用8080或其他站点作为目标。

当前十个用例覆盖：

1. 取消LEGACY日期核对：保留原来源与记录，不发出PUT。
2. 取消清空已有日期：记录未改变，页面中的空输入仍作为草稿保留。
3. 取消丢弃草稿：保留输入；确认丢弃后重新显示已保存值。
4. 最后一集完成再退集：首页数量、详情状态和集数联动，逐集记录正确新增和删除。
5. 两个独立登录窗口同时编辑同一集：第一个保存成功，第二个收到真实409、保留草稿并禁用保存；取消重载保留草稿，确认重载后显示服务端新值。
6. 主题色与深浅按钮：文字说明用途和切换目标，刷新后保留选择；语言切换同步提示与可访问名称，实际图标字体已从本地加载。
7. 添加区与顶部：1440/768/390/360像素深浅主题无页面横向溢出，字段和操作完整显示；桌面添加区不超过650像素且控件至少44像素，保存截图并核对备注焦点。
8. 手机添加：必填与评分范围阻止非法提交，空名称检索提示及图片文件选择入口可用；真实添加一次，备份读取核对资料、标签、状态与旧番选项，表单重置。完成日期按既有观看规则规范化，不能把计划作品误记为已完成。

9. 桌面与360像素手机：三视图搜索结果一致，键盘打开作品，关闭详情后焦点返回作品名称；深浅主题无页面或详情横向溢出，关闭和进退集至少44像素。
10. 已加载图表切换深浅主题：文字与网格同步，实例与数据不变，切回浅色恢复原配色；保存深浅截图。

测试只用HTTP读取核对持久化结果，不模拟业务API。浏览器脚本异常会使测试失败，等待基于可见元素和响应，不用固定睡眠掩盖异步问题。单worker运行，无自动重试。

## 本地运行

需要Node.js 22、Java 17或更高版本、本地MySQL与mysql客户端、可创建和删除演示库的数据库账号。按照[演示说明](持续集成与演示.md)配置JAVA_HOME、DB_USER、DB_PASS与回环数据库端口。

```powershell
mvn clean verify
npm ci
npx playwright install chromium
npm run test:e2e
```

这套浏览器回归由上述命令显式运行，不受OTAKULOG_DEMO_TEST控制。现有Node行为测试仍无需npm依赖，应用编译与日常运行也不需要npm。

package-lock.json锁定测试依赖和浏览器版本；Chromium是专用测试浏览器，不借用用户已有窗口、Cookie或浏览记录。Linux CI使用`npx playwright install --with-deps chromium`补齐系统依赖。

## 网络与诊断边界

页面原有Chart.js、Sortable、marked和DOMPurify的CDN请求在测试中映射到锁定的本地开发依赖；其余外部请求阻止，Service Worker禁用。本地图标CSS/WOFF2从真实应用加载，已核对字体就绪与实际请求；核心测试不依赖CDN可用性，但**不证明其他实际CDN、离线启动和外部服务已验收**。图标不再引用失效的外部脚本，其余生产CDN版本未改变。

失败截图、页面诊断和trace保存在test-results/，HTML报告在playwright-report/。两个目录和node_modules/不入git。查看报告可使用`npx playwright show-report`。CI将浏览器输出和诊断随其他报告保存7天。诊断可能包含本次临时演示登录凭据与Cookie，库清理和进程停止后即不可用；不捕获自用会话。

正常结束已逐用例验证数据库清理；强制终止、断电或进程无法停止时仍遵循[演示清理边界](持续集成与演示.md)，不要按库名前缀批量删除。

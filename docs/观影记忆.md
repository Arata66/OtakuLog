# 观影记忆

## 写下与回看

打开本地作品详情，在“观影记忆”留下自由感想。一句话或长文均可，原文中的空格与换行会保留。可以同时记录“打动我的地方”和“不满意的地方”，不用给每个方面打分。既有作品备注仍保留，未自动转成历史感想。

语境可选随手记、初看、回望或重看；由用户主动选择，不按时间间隔分类。观看日期可留空，记录时间只表示写下这条感想的时刻，不能代替真实观看日期。评价范围可写“第一季”“电影”“原作后续”等，避免将不同版本混在一起。

每部作品允许多条记忆，按记录时间倒序回看，每页20条。新增回望保留此前记录。编辑只修改选中的条目，删除只删除该条；删除整个作品时，其记忆也随作品清理。

感想为纯文本显示，可包含角色或剧情内容，未自动生成对外分享。首版实现记录、回看和完整备份；AI整理、口味画像、类型命名与个性化推荐是后续阶段，本阶段不向外部模型发送感想。

## 输入与失败处理

感想必填，最多16000个Java字符；喜欢与不满意的原因各2000字符；评价范围200字符。观看日期允许未知，已知日期为1000年至今天。语境默认随手记。

保存期间避免重复提交，失败后保留文字以便重试。新记忆使用稳定UUID，同一条内容重试不会重复新增；更改已提交编号的内容会冲突。编辑和删除携带读到的版本，另一个窗口已改动时返回409；页面保留当前稿件，先重新加载并核对后再保存。

关闭、翻页或重载涉及未保存文字时，会提示确认。私人接口使用登录会话与CSRF，Service Worker不缓存记忆API；退出后不能从离线API缓存读取。

## 数据结构与事务

Flyway V10新增`anime_memory`表，`anime_id`外键关联作品并级联删除。实体的版本是普通非负Long字段；创建版本0，真实修改加一。写事务先取得所属作品的悲观锁，单删与批删作品复用同一锁顺序；ORM刷新后返回数据库实际时间精度。列表读取使用一致性只读事务。

| 字段 | 含义 |
|------|------|
| `id` / `animeId` | 当前数据库记忆与所属作品编号 |
| `key` | 稳定UUID，提交防重及跨备份识别同一条记忆 |
| `content` | 用户原文 |
| `liked` / `disliked` | 可选喜欢与不满意的原因，允许并存 |
| `scope` | 用户填写的评价范围 |
| `context` | NOTE、INITIAL、REFLECTION、REWATCH |
| `watchedDate` | 用户主动提供的观看日期，可空 |
| `createdAt` / `updatedAt` | 记录时间与最后修改时间 |
| `version` | 编辑及删除时核对的版本 |

既有作品资料、进度、评分和逐集日期不因记录感想而改变。升级只创建空记忆表，不猜旧番感受、观看日期或人生人格。

## API

均需要登录；POST、PUT、DELETE需要当前CSRF令牌。返回沿用`ApiResponse`。

| 方法与路径 | 请求与返回 |
|------------|------------|
| `GET /api/anime/{id}/memories?page=0&size=20` | data包含animeId、page、size、totalEntries、entries；size为1至50 |
| `POST /api/anime/{id}/memories` | 传key与正文；返回新增条目，同内容同key重试返回原条目 |
| `PUT /api/anime/{id}/memories/{memoryId}` | 正文与expectedVersion，返回修改后条目；key可省略但不可改变 |
| `DELETE /api/anime/{id}/memories/{memoryId}?expectedVersion=0` | 删除成功；过期版本409 |

新增正文示例：

```json
{
  "key": "0d2e49fe-719c-4bd8-909c-3615bbfc2b8a",
  "content": "结幕时还想再听一次音乐。",
  "liked": "演出与音乐",
  "disliked": "部分情节",
  "scope": "电影",
  "context": "INITIAL",
  "watchedDate": null
}
```

未知作品及错误归属返回404，非法文字/日期/分页/版本返回400，稳定编号冲突或过期版本返回409。修改时先核版本，再处理内容；内容完全相同的保存不递增版本。不要自动重试冲突写入。

## 完整备份与验收

版本2完整备份新增`memories`，含稳定编号、文件内作品引用、全部感想字段、日期、版本和审计时间。本地与WebDAV使用同一校验与事务。旧版本1和作品数组仍可恢复，不删除本地额外记忆；同编号内容或所属作品不同则整批冲突，避免覆写新的表达。详见[备份与恢复](备份与恢复.md)。

自动化包含接口原文/追加/修改/删除/权限/版本、备份往返/重复/兼容/冲突/回滚及真实MySQL迁移/重启/并发/删除。浏览器验收使用随机隔离MySQL与虚构样例，清理仅针对本次创建的数据库；用户聊天中的感想不自动写入自用库。具体执行命令见[浏览器核心回归](浏览器核心回归.md)。
